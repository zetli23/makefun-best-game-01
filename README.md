# Zein's Number Duel

A minimal, replayable number-guessing game for Node 22 (standard library only).

## How to run

```bash
node main.ts
```

## Features

- Three difficulties: Easy (1–50, 8 lives), Medium (1–100, 6 lives), Hard (1–200, 4 lives)
- Tracks your best (fewest guesses) score per session
- Clean terminal UI, input validation
